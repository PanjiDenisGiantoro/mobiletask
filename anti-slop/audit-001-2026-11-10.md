# Audit 001 — Halaman Task (tasks_screen.dart, task_tile.dart)

Scope: `lib/app/screens/tasks_screen.dart`, `lib/app/widgets/task_tile.dart`.
Konteks: aplikasi utilitas (task management), bukan landing page — rule-rule
antislop yang soal marketing (fake stats, testimonial, FAQ, hero section) tidak
relevan di sini. Fokus temuan: identitas visual, konsistensi, dan bug UX nyata.

## Temuan

1. **[Konsistensi bahasa]** Teks UI pakai Inggris ("Tasks", "To Do", "Done",
   "High/Medium/Low", "No completed tasks yet", "All tasks done!") padahal
   seluruh layar lain di app (Home, Projects, HRIS) pakai Bahasa Indonesia.
   — *Prioritas: HIGH (konsistensi identitas)*

2. **[Bug nyata] Urgent vs High tidak bisa dibedakan** — `TaskTile._priorityColor`
   memetakan `urgent` dan `high` ke warna yang sama persis (`AppColors.error`),
   dan filter chip "High" menggabungkan keduanya. Dua level prioritas berbeda
   jadi tidak terlihat beda sama sekali di UI.
   — *Prioritas: HIGH (fungsional, bukan cuma visual)*

3. **[Generik] Task card terlalu generik** — card putih polos + shadow tipis +
   checkbox + pill prioritas: fungsinya oke tapi tidak ada identitas/aksen
   yang membuatnya terasa milik Flovig (tidak ada tautan warna ke proyek,
   tidak ada hierarki fokus selain pill prioritas).
   — *Prioritas: MEDIUM*

4. **[Generik] Progress banner statis** — bar progres di atas cuma angka +
   bar polos, tidak ada aksen/momentum visual (misal: highlight saat 100%,
   warna beda saat tertinggal jauh dari target hari ini).
   — *Prioritas: LOW*

5. **[Fungsional] Filter cuma berdasarkan prioritas** — tidak ada filter
   status (To Do/In Progress/Review) atau proyek, padahal tab Task di layar
   Detail Proyek sudah punya filter status yang lebih lengkap (`PhChipBar`).
   — *Prioritas: MEDIUM*

6. **[Discoverability] Swipe-to-delete tidak ada petunjuk visual** — row bisa
   di-swipe kiri untuk hapus (`Slidable`) tapi tidak ada indikasi apa pun di
   card bahwa itu bisa di-swipe.
   — *Prioritas: LOW*

7. **[Ambiguitas kecil] `type` vs `project` saling tutup** — `TaskTile` cuma
   menampilkan salah satu: ikon+label `type` ATAU nama `project`, tidak pernah
   dua-duanya. Konteks proyek jadi hilang kalau `type` terisi.
   — *Prioritas: LOW*

## Tidak ditemukan masalah signifikan di:
Gradient berlebihan, glassmorphism bertumpuk, badge/ikon AI generik, border
radius pill-semua, shadow/glow berlebihan, statistik/testimoni palsu — layar
ini relatif bersih dari slop pattern khas landing page karena memang bukan
landing page.
